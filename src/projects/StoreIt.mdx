This project is for understanding a CRUD functionality of RESTful API, which consists of Create, Read, Update, Delete with Model-View-Controller architecture. An attempt to
clone some of the Enterprise Resource Planning system (ERP) feature, mainly storing stock data. It's also a project that I want to try to use only HTML, CSS, and JavaScript
to make as it will be a good foundation in the long run.

### Objective:

- To understand the CRUD functionality and how to work with APIs.
- To learn about how to make a fullstack web application without relying on external libraries.
- To solidify my fundamental with HTML, CSS, and JavasScript.

### What I learned:

1. Due to using only vanilla JavaScript, I learn how to manually manipulate DOM, handling error with <code>try</code> and <code>catch</code>.
2. Learned how to make basic APIs without rely on libraries, and seeing how things work.
3. Know how to use MongoDB for NoSQL database, Express and Node.js to setting up backend, and asynchronous JavaScript with <code>async</code> and <code>await</code>.
4. Utilizing Model-View-Controller, which result in model (data model to validate the data type), view as HTML template, and controller for handling APIs (POST, GET, PUT, DELETE).
