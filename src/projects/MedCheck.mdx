This is my senior project that intended to optimize the reverse logistic process
within Ramathibodi Hospital, which is considered prestigious hospital and got
runner-up status in a project competition hosted by Engineering Institute of
Thailand (EIT). I'm responsible for frontend development and UX/UI design with
tools such as Figma and Python. This is my first project, so expected a lots of
roughness in the UI and design as I'm new to this.

### The problem

---

The project required us to talk with the clerks within Ramathibodi Hospital to find the problem and the solution, which consists of:

- Data inaccuracy
- Clunky working method (manual calculation with Excel)
- Large dataset
- No one actually responsible for this task, as it is low priority

From this, we can understand the pain point is that the **clerk aren't skilled in Excel**, which should be solved by training them. However, this is the low priority task
that doesn't really need to spend resources to train yet still a big problem as the cost can added up to 400,000 THB per year.

### Action

---

Our project were mostly done with waterfall methodology which began by making user journey, then user flow diagram, and wireframing the application to communicate about the design, and developed using Pyside6, styling with QML and
calculation logic with Python (Pandas). Then we conducted a tests to gain feedback for improving an application, by comparing the app's result with their past report, recorded time,
and trial use for continuous feedback. Lastly, we also documented the instructions on how to use an application.

### Result

---

After the improvement, we can speeding up an operation time approximately 99.39% faster with the total data accuracy and reduced the monthly cost which saved 35,000 THB per month.
