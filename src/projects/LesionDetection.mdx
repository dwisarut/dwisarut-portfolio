This is the contracted project commissioned by the doctor, which is the automated python script that ran when taking screenshot in the CT-scan in order to find the tumor, wound, or
other anomaly within the patient body. I'm responsible for **fine-tuning the parameters** that utilized K-mean cluttering and post-processing parameters, while also **migrating the script** from
direct file input to automated in-memory input pipeline.

_**Disclaimer:** Preview image was generated by Gemini 3, as I can't show the actual data due to patient privacy. However, the preview image are replicated similarly to the actual output._

### The problem

---

There are multiple problems that hinder our progress, mostly technical stuff with some timing inconveniences.

- Inconsistent input that incompatiable with tuned pipeline (eg. file types).
- Difficulty in testing the result with accurate environment, as they use the paid version of RadiAnt DICOM Viewer, we can't conveniently test it with our machine.
- Small test samples.

### Action

---

1. Change the input image to parse screenshot into pipeline directly, and tuning the parameters for pre-processing, segmentation, and post-processing.
2. Export the executable file (.exe) for client to test, and receive feedback for improvement.
3. We have a limited test samples, so we assign the passable area detection coverage to be around 80% with ± 10% tolerance.

### Result

---

1. The pipeline can detect the tumor or the area marked by the crosshair, fulfilled the requirement.
2. The pipeline can detect the area and mark correctly, with the average of area coverage at around 80% as we intended.
