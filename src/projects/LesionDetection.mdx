This is the contracted project commissioned by the doctor, which is the automated python script that ran when taking screenshot in the CT-scan in order to find the tumor, wound, or
other anomaly within the patient body. I'm responsible for **fine-tuning the parameters** that utilized K-mean cluttering and post-processing parameters, while also **migrating the script** from
direct file input to automated in-memory input pipeline.
